# IBAN helper screenshots

Drop real bank-app screenshots here; the driver app shows them in the
"Where do I find my IBAN?" helper (cashout step 2 and profile → add account).
A missing file is fine — the helper falls back to text only.

| File      | Bank             | What to capture                                                   |
|-----------|------------------|-------------------------------------------------------------------|
| `tbc.png` | TBC              | TBC app → Accounts → GEL account → details, IBAN visible          |
| `bog.png` | Bank of Georgia  | mBank app → Accounts → GEL account → details, IBAN visible        |

Guidelines
- Portrait phone screenshot, PNG or JPG renamed to .png, ~1080 px wide is plenty (keep under ~300 kB).
- Blur or cover the real account number, name and balance, or use a test account.
- Optionally circle/underline the IBAN line in red so it's obvious at a glance.
- File names are lower-case bank labels: `tbc.png`, `bog.png`.
